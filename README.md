Установка и запуск

1. Требования
Python версии >= 3.10.

2. Установка зависимостей
pip install -r requirements.txt

3. Подготовка данных
Убедитесь, что файлы `consumption.parquet`, `market_access.parquet` и `connection.parquet` находятся в директории `data/`.

4. Запуск пайплайна
python main.py
